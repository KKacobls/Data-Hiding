# TPE-DNA 16×16 多樣像素數值示範

此資料夾用於課堂投影片：保留五種特殊像素對 (120,120) EZ、(185,182) EN1、(225,200) EN2、(250,10) CN、(0,255) NC，第 6 組為 (120,120) EZ；其餘 92 組以固定種子產生**不同灰階平均值與安全差值**，避免全部都是 120。

## 執行

需要 Python 3.9+，不需額外安裝套件。

```bash
python tpe_dna_16x16/demo.py --seed 20261110
python -m unittest discover -s tpe_dna_16x16 -p "test_*.py" -v
```

程式會產生 `tpe_dna_16x16/output/`：
- `original.tsv`：原始 16×16 矩陣，複製貼上 Excel 即為 16 欄。
- `pre_encrypted.tsv`：嵌入後矩陣。
- `restored.tsv`：取出資料後還原矩陣。
- `pairs.tsv`：98 組每組原始像素、類型、嵌入 bit、修改結果。
- `report.json`：分類、容量、壓縮、測試統計。

## 必須告訴老師的限制

**這不是已完整重現論文 TPE-DNA！** 本程式只示範 A/E 區域、五種像素分類、輔助資訊彙整、RLE、差值擴展或差值 LSB 的**預加密嵌入**，未做 DNA 編碼、混沌序列、A 區調整、置亂及其完整解密。

1. RLE 的 1 bit 值 + 7 bits 次數封裝是**教學自訂規則**，不是已驗證的論文原始封裝方式。
2. 解密器目前把每組原始分類（98 個類別）當成**外部已知資訊**，並使用額外已知的 RLE 組數與 payload 長度。這並非純影像自包含的可逆性驗證，若計算完整儲存成本須將外部資訊另外計入。
3. A 區原始高 2 bits 這次因為都是 00，壓縮結果與原先投影片範例相同，但 A 區實際數值在 4 到 63 之間多樣變化；這是保留 RLE 低成本的實驗設定。
4. 故意將多數 E 區配對設計為 EN1，以維持壓縮率；**不是對真實醫學影像的統計推論，也不是自然圖片資料集**。
5. 32 bits 只表示 E 區內嵌 payload；若由解密端外部接收分類表等側資訊，不能宣稱完整演算法不需額外儲存。

## 如何放入 PPT

將 `original.tsv` 和 `pre_encrypted.tsv` 貼到 Excel，再複製表格至 PPT。第 8–12 頁五種案例不必更動；**第 5、15、18、19、23、24 頁需依新的矩陣與分類統計同步更新**。五種特殊例子與前六組的實際嵌入順序不變。
